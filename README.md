# Мастерская Doom-мода

Редактор текстур и карт для Doom-мода на Unity: https://sunakle.github.io/doom-mod-editor/

- Перерисовка всех текстур Freedoom (стены, полы, спрайты, интерфейс), поддержка пера
  графического планшета: нажим, ластик на обратном конце, пипетка на кнопке пера.
- Редактор карт с видом сверху: зоны, двери, кислота, монстры и предметы.

Если на компьютере запущен `Запустить сайт.bat` из Unity-проекта, правки сразу пишутся в проект.
Без него они хранятся в браузере и переносятся в Unity при следующем запуске сервера.

Текстуры и спрайты — [Freedoom](https://freedoom.github.io/), лицензия в `FREEDOOM-COPYING.txt`.
Этот репозиторий собирается скриптом `tools/build_pages.py` из Unity-проекта; правьте сайт там.
